# 部署指南（保姆级）

> 目标：把这个应用从「本地运行」变成「全世界都能访问」。
> 全程只需浏览器操作，约 30 分钟。遇到任何一步卡住，把截图发出来即可。

---

## 第一步：把代码放到 GitHub（约 10 分钟）

### 1.1 注册/登录
1. 打开 https://github.com → 右上角 Sign in（没有账号先 Sign up，邮箱注册即可）
2. 登录后，右上角头像旁边点 **+** → **New repository**
3. 填写：Repository name 填 `interview-scheduler`，选 **Public**（开源），其他全默认 → **Create repository**
4. 页面会显示一段命令，**先别关这个页面**

### 1.2 安装 GitHub 命令行工具（在本机终端，一次性）
1. 打开「终端」App（访达 → 应用程序 → 实用工具 → 终端）
2. 粘贴运行：
   ```
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```
   （按提示输一次开机密码；Homebrew 是 Mac 装软件的标准工具）
3. 装好后运行：
   ```
   brew install gh
   ```

### 1.3 登录 GitHub CLI 并推送（一次性登录，之后我或你都可以继续操作）
1. 终端运行：`gh auth login`
2. 依次选择：GitHub.com → HTTPS → **Login with a web browser**
3. 终端会显示一个 8 位代码，浏览器会打开授权页 → 粘贴代码 → 点授权
4. 回到终端看到 ✅ 即完成
5. 告诉我「已登录」，我来执行推送；或者你自己运行（把 <你的用户名> 换成你的 GitHub 用户名）：
   ```
   cd "/Users/wuzonghui/Documents/deepseek harness/interview-scheduler"
   git remote add origin https://github.com/<你的用户名>/interview-scheduler.git
   git branch -M main
   git push -u origin main
   ```

## 第二步：部署到 Vercel（约 10 分钟）

1. 打开 https://vercel.com → **Sign Up** → 选 **Continue with GitHub**（用刚注册的 GitHub 登录）
2. 登录后点 **Add New… → Project**
3. 列表里选 `interview-scheduler` → **Import**
4. 全默认 → **Deploy**
5. 约 1-2 分钟后出现 🎉 和网址（形如 https://interview-scheduler-xxx.vercel.app）——**这就是你的线上地址**

---

## 第三步：创建免费数据库 Supabase（约 10 分钟，阶段 1 加入账号功能时才需要）

1. 打开 https://supabase.com → Start your project → 用 GitHub 登录
2. New project：名字随意，密码点「Generate」生成并**保存好**，区域选离你最近的 → Create
3. 项目里左侧 **Project Settings → Database → Connection string → URI**，复制整串
4. 回到 Vercel 项目 → Settings → Environment Variables → 添加：
   - 名称 `DATABASE_URL`，值 = 刚复制的连接串（把其中的 [YOUR-PASSWORD] 换成你生成的那个密码）
5. 保存后点 Deployments → 最新一次 → Redeploy

---

## 第四步：Google 日历 OAuth（阶段 2 需要）

1. https://console.cloud.google.com → 新建项目 → 启用 Calendar API
2. 凭据 → 创建 OAuth 客户端 ID → Web 应用
   - 授权来源（Authorized origins）：填 Vercel 给你的网址
   - 重定向 URI：`https://你的域名/api/auth/callback/google`
3. 把 Client ID / Secret 填进 Vercel 环境变量 `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` → Redeploy

---

## 常见问题

- **终端说 command not found**：先完成 1.2 的 Homebrew 安装。
- **推送时要求输入密码**：说明 gh 登录没生效，重跑 `gh auth login`。
- **Vercel 部署失败**：把失败日志截图发我。
- **想改代码再上线**：改完 push 到 main，Vercel 自动重新部署。

> 提示：以上第二、三、四步都可以先不做——现阶段把第一步做完（代码上 GitHub），后续步骤到对应阶段再执行即可。
